# Pocket City: Park Slope

An interactive isometric diorama of a 200 m square of 5th Avenue in Park Slope, Brooklyn.
Built with April Zhu's Pocket City skill (MIT, https://april-zhu.com/pocketcity).

Data: © OpenStreetMap contributors (ODbL); NYC 2015 Street Tree Census; NYC MapPLUTO; NOAA NCEI 1991–2020 normals.
Sources for every on-screen fact are linked in the page's field notes.
